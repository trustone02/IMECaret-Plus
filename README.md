# IMECaret Plus (아이엠이캐럿 플러스) v1.0

Windows에서 텍스트 커서(커서) 바로 옆에 실시간 **한/영 입력 상태**를 깔끔하게 띄워주는 프로그램입니다.

한컴오피스 한/글(HWP), SSMS(SQL Server Management Studio), 오피스, Windows 11 검색창 등 모든 환경에서 한/영 상태를 오차 없이 정확하게 확인할 수 있습니다.

---

## 📥 다운로드 및 설치 (가장 쉬운 방법)

일반 사용자께서는 아래 링크에서 설치 파일만 받아 실행하시면 됩니다. (개발 도구나 소스코드는 전혀 설치하실 필요 없습니다!)

1. **[최신 설치 파일(IMECaretPlus-Setup.exe) 다운로드](https://github.com/trustone02/IMECaret-Plus/releases)**
2. 다운로드한 `IMECaretPlus-Setup.exe`를 실행하여 설치합니다.
   * "Windows 시작 시 자동으로 실행"을 선택하시면 컴퓨터를 켤 때마다 자동으로 실행됩니다.
3. 설치 없이 바로 실행하고 싶으신 분은 압축 파일의 `IMECaretPlus.exe`를 더블클릭하시면 즉시 실행됩니다.

---

## ✨ 핵심 기능

* **한컴오피스 한/글(HWP) 한/영 상태 완벽 확인:**
  * 아래한글 문서 작성 중 실시간 한/영 입력 상태(`가` / `a`)가 커서 옆에 정확하게 표시됩니다.
* **SSMS 등 데이터베이스 도구의 전자(전각) / 반자(반각) 확인:**
  * 쿼리 오류를 유발하는 전각(Full-width) 상태를 실시간으로 감지하여 경고 색상으로 오타를 방지합니다.
* **Windows 11 작업표시줄 검색창 최적화:**
  * 작업표시줄 검색창 뒤로 커서 배지가 숨지 않고 항상 최상단에 안정적으로 표시됩니다.
* **원클릭 제거(언인스톨):**
  * 제어판에서 프로그램 삭제 시 찌꺼기 파일과 트레이 아이콘 설정까지 깨끗하게 자동 삭제됩니다.

## 📌 화면 표시 안내

| 입력 상태 | 배지 모양 | 설명 |
|:---:|:---:|---|
| **한글** | `가` | 한글 입력 상태 (파란색) |
| **영문 소문자** | `a` | 일반 영문 입력 상태 (주황색) |
| **영문 대문자** | `A` | Caps Lock 켜짐 (대문자 고정) |
| **전자(全角) 경고** | `Ａ` / `가` | SSMS 등에서 전각 상태 감지 시 경고 |
| **일본어** | `ひ` / `カ` | 일본어 히라가나 / 가타카나 모드 |

---

## ⚙️ 설정 방법

작업표시줄 오른쪽 아래(트레이)의 **IMECaret Plus** 아이콘을 마우스 우클릭하면 설정을 바꿀 수 있습니다.

* **소리 알림:** 한/영 키를 누를 때 소리를 켤지 끌지 설정
* **표시 위치:** 커서 오른쪽, 커서 위쪽, 커서 아래쪽(기본값) 중 원하는 위치 선택
