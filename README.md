# IMECaret Plus (아이엠이캐럿 플러스) v1.1.4

Windows에서 텍스트 커서 바로 옆에 실시간 **한/영 입력 상태**를 깔끔하게 띄워주는 프로그램입니다.

한컴오피스 한/글(HWP), SSMS(SQL Server Management Studio), MS 오피스 등 다양한 작업 환경에서 한/영 상태를 오차 없이 정확하게 확인할 수 있습니다.

---

## 📥 다운로드 및 설치 (가장 쉬운 방법)

일반 사용자께서는 아래 링크에서 설치 파일만 받아 실행하시면 됩니다. (개발 도구나 소스코드는 전혀 설치하실 필요 없습니다!)

1. **[최신 설치 파일(IMECaretPlus-Setup.exe) 다운로드](https://github.com/trustone02/IMECaret-Plus/releases)**
2. 다운로드한 `IMECaretPlus-Setup.exe`를 실행하여 설치합니다.
   * "Windows 시작 시 자동으로 실행"을 선택하시면 컴퓨터를 켤 때마다 자동으로 실행됩니다.
3. 설치 없이 바로 실행하고 싶으신 분은 압축 파일의 `IMECaretPlus.exe`를 더블클릭하시면 즉시 실행됩니다.

---

## ✨ 핵심 기능

* **한컴오피스 한/글(HWP) 한/영 상태 완벽 확인:**
  * 아래한글 문서 작성 중 실시간 한/영 입력 상태(`가` / `a`)가 커서 옆에 정확하게 표시됩니다.
* **SSMS 등 데이터베이스 도구의 전자(전각) / 반자(반각) 확인:**
  * 쿼리 오류를 유발하는 전각(Full-width) 상태를 실시간으로 감지하여 경고 색상으로 오타를 방지합니다.
* **초경량 & 초고속 (Zero-Latency):**
  * Rust 기반 순수 Win32/UIA 하이브리드 엔진으로 개발되어 CPU 점유율 0% 및 0ms(체감 지연 0초)의 즉각적인 한/영 토글 반응성을 제공합니다.
* **원클릭 제거(언인스톨):**
  * 제어판에서 프로그램 삭제 시 찌꺼기 파일과 트레이 아이콘 설정까지 깨끗하게 자동 삭제됩니다.

## 📌 화면 표시 안내

| 입력 상태 | 배지 모양 | 설명 |
|:---:|:---:|---|
| **한글** | `가` | 한글 입력 상태 (파란색) |
| **영문 소문자** | `a` | 일반 영문 입력 상태 (주황색) |
| **영문 대문자** | `A` | Caps Lock 켜짐 (대문자 고정) |
| **전자(全角) 경고** | `Ａ` / `가` | SSMS 등에서 전각 상태 감지 시 경고 |
| **일본어** | `ひ` / `カ` | 일본어 히라가나 / 가타카나 모드 |

## 🔔 아래한글(HWP) 사용 시 꼭 확인하세요

아래한글은 한/영 상태를 외부 프로그램이 읽을 수 없어서, IMECaret Plus는 **한/영 키 입력**을 따라가며 상태를 표시합니다.
그런데 아래한글에는 한/영 키를 누르지 않아도 입력 상태를 **스스로 바꿔 버리는 기능**이 있습니다. (예: 자음만 연속으로 입력하면 자동으로 영문으로 전환)
이 기능이 켜져 있으면 표시와 실제 입력이 어긋날 수 있으니, 아래한글에서 **꺼 두시기를 권장합니다.**

1. 아래한글 메뉴에서 **도구 → 글자판 → 글자판 자동 변경(A)** 을 선택해 **해제**합니다.
2. 한/영 전환은 항상 **한/영 키**로만 하세요.

> 💡 아래한글을 한글 입력 상태로 켜 두고 이 프로그램을 처음 실행했거나, 위 자동 변경으로 상태가 바뀌어 표시가 반대로 보이면 한/영 키를 한 번 눌러 맞춰 주세요.

## 🛡️ 백신(Windows 보안)이 설치 파일을 차단할 때

코드 서명이 없는 새 프로그램은 Windows 보안의 **클라우드 자동 판정(머신러닝)** 이 오탐하는 경우가 있습니다.
(예: `Trojan:Win32/Bearfoos.B!ml` 같은 `!ml` 로 끝나는 일반 탐지 이름)

- 이 프로그램은 오픈소스이며, 한/영 키 입력 **여부**만 판단하고 입력한 **내용은 저장하거나 전송하지 않습니다.** (소스 코드 전체 공개)
- 차단되면 **Windows 보안 → 바이러스 및 위협 방지 → 보호 기록**에서 해당 항목을 열고 **작업 → 허용(복원)** 한 뒤 다시 실행하세요.
- 설치 파일이 계속 지워지면 **무설치 포터블(`IMECaretPlus-v*-Portable.zip`)** 을 받아 압축 해제 후 사용하세요.
- 받은 파일이 변조되지 않았는지는 각 릴리스 노트의 **SHA256** 값과 비교해 확인할 수 있습니다. (PowerShell: `Get-FileHash 파일명`)
- 오탐은 [Microsoft에 신고](https://www.microsoft.com/wdsi/filesubmission)하여 해소할 수 있으며, 서명이 없는 새 파일은 사용자가 늘수록 판정이 안정되는 경향이 있습니다.

## ⚙️ 설정 방법

작업표시줄 오른쪽 아래(트레이)의 **IMECaret Plus** 아이콘을 마우스 우클릭하면 설정을 바꿀 수 있습니다.

* **소리 알림:** 한/영 키를 누를 때 소리를 켤지 끌지 설정
* **표시 위치:** 커서 오른쪽, 커서 위쪽, 커서 아래쪽(기본값) 중 원하는 위치 선택

## 🔏 코드 서명 및 개인정보 안내

* **코드 서명:** 현재 배포 파일(`IMECaretPlus.exe`, `IMECaretPlus-Setup.exe`)에는 **코드 서명이 적용되어 있지 않습니다.** 그래서 일부 PC의 백신이 오탐할 수 있습니다(위 안내 참고).
* **빌드:** 릴리스 파일은 이 저장소의 소스에서 GitHub Actions로 빌드할 수 있으며, 각 릴리스 노트에 SHA256 해시를 적어 둡니다.
* **유지보수:** [trustone02](https://github.com/trustone02) (1인 유지보수)

### 개인정보 및 보안 (Privacy policy)

* 이 프로그램은 **한/영 키 상태와 입력창 위치를 화면 표시용으로만** 사용합니다. 입력한 글자 내용은 **저장하지도, 외부로 전송하지도 않습니다.**
* 전역 키 감시(Raw Input)는 한/영 키와 아래한글의 한/영 상태 추정에만 쓰입니다. 로그(`%LOCALAPPDATA%\IMECaretPlus\imecaret.log`)에는 키 종류(한/영 등)와 상태 변화만 기록되며 글자 내용은 없습니다.
* 네트워크 통신을 하지 않으며, 어떤 데이터도 외부로 보내지 않습니다.
* 시스템 변경: 설치 시 선택한 경우에만 시작 프로그램(Run 키, 시작 폴더 바로가기)에 등록하고, 제거하면 모두 삭제됩니다.
